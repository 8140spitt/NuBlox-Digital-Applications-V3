# Product Analysis & Traceability Evidence

> **Evidence archive — not the NuBlox product manual.**
>
> Start with the [NuBlox Product Handbook](../../handbook/README.md).

This directory preserves the product-discovery evidence used to establish NuBlox Construction & The Built Environment.

It contains employment/job reconciliation, construction-career baselines, Work-Product decomposition waves, architecture-gap registers, stakeholder reviews and the original V3 product charter.

## Use this material when

- validating why a product decision exists;
- tracing a Job Profile or Work Product back to source analysis;
- resolving a documented architecture gap;
- checking construction/built-environment career coverage;
- reviewing historic stakeholder evidence.

## Do not use it as

- the product handbook;
- the user guide;
- the administrator guide;
- a statement that a capability is implemented.

For target behaviour use `docs/handbook/`. For actual runtime state use [Product State & Roadmap](../../handbook/08-product-state-and-roadmap.md).

New implementation work should not create another broad analysis wave unless genuinely new evidence is required.
