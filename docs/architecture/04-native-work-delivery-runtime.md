# 04 — Native Work-Delivery Runtime

The Native Work-Delivery Runtime is the execution layer that turns governance into performed work.

## Core chain

```text
Function / Delivery Domain
  → Job Profile
    → Organisation Unit / Position / Person
      → Operating Context
        → Functional Deployment
          → Assignment
            → Work
              → Deliverable
                → Review / Decision / Approval
                  → Issue / Acceptance
                    → Evidence / Controlled Record
```

## Functional Deployment

A deployment binds capability to an operating context. It can constrain:

- function or delivery domain;
- job profile;
- organisation unit;
- position and/or person;
- project, programme, contract, package, site, facility, system or asset;
- scope;
- competence requirements;
- delegated authority;
- effective dates;
- capacity;
- responsibility; and
- assurance requirements.

## Work

Work is an executable obligation. A work item is not the domain object itself and does not replace domain truth.

## Deliverables

A Deliverable Item represents the obligation and controlled identity of an output. It is **not a file**.

A deliverable can be fulfilled by structured native data, one or more controlled Information Containers, physical evidence, external representations or a governed combination of these.

## Decisions

A Decision is attributable, immutable evidence. Recording a decision is separate from performing the authorised domain state transition.

## Control chain

Authoring, review, approval, issue, acceptance, supersession and rework are explicit governed states where required by the deliverable type and operating context.
