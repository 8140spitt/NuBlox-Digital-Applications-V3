# 03 — Functional Domain Framework

NuBlox defines **29 governed enterprise functions**. A function is not a screen, department or mini-application.

## Each function contains

- purpose and mandate;
- scope and boundaries;
- accountable ownership;
- policies, standards and procedures;
- processes, activities and tasks;
- native tools and workspaces;
- controlled object and deliverable types;
- lifecycle, workflow and change rules;
- participating job profiles;
- competence requirements;
- decision rights and delegated authority;
- assurance and evidence requirements;
- KPIs and performance measures;
- audit requirements; and
- deployment rules.

## Functional operating chain

```text
Govern
  → Define
    → Deploy
      → Execute
        → Produce
          → Control
            → Assure
              → Evidence
                → Improve
```

## Separation of concepts

A **Function** describes governed organisational capability.

A **Department / Organisation Unit** describes organisational structure.

A **Job Profile** describes a governed capability profile for work a person may perform.

A **Position** is an organisational seat.

A **Person** is a party.

A **Deployment** authorises or requires capability to be exercised in a specific operating context.

These concepts may be related, but none is interchangeable with another.

## Cross-functional operation

Functions share the Enterprise Kernel. Cross-domain processes therefore link common enterprise objects instead of copying them between modules.
