# NuBlox Evidence Archive

This directory preserves the evidence behind the NuBlox product model.

It is **not** the primary product documentation.

Start with the [Product Handbook](../handbook/README.md), [User Guide](../user-guide/README.md), [Administrator Guide](../admin-guide/README.md), [System Architecture](../handbook/07-system-architecture.md) and [Product State & Roadmap](../handbook/08-product-state-and-roadmap.md).

## Contents

- `product-analysis/` — job architecture, Work-Product decomposition, reconciliation, stakeholder reviews and product-discovery evidence.
- `benchmarks/` — market/vendor/standards benchmarking used to challenge the model.

The evidence archive exists for traceability. Routine implementation should update the Handbook, user/admin documentation, ADRs, tests or stable interface documentation rather than create another broad discovery wave.
