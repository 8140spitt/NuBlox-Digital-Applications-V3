# NuBlox Archive

The archive contains historical and supporting material that is deliberately kept **outside the live product documentation**.

For current documentation, use [docs/README.md](../docs/README.md).

## Documentation archive

`archive/documentation/` contains:

- historical architecture reference;
- prior business-function mapping artefacts;
- detailed canonical/data-model studies;
- prior design-system papers;
- product-analysis/reconciliation evidence;
- market and vendor benchmark evidence.

These files are retained for provenance and investigation. They should not be treated as current product documentation unless a live document explicitly points to them.
