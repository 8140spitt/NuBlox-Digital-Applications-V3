# 84 Construction & Built Environment Jobs

## Purpose

This is the live sector-job baseline used by the NuBlox product model.

The 84 jobs represent the identified Construction & Built Environment occupations that NuBlox must be capable of governing, delivering and deploying.

They do **not** replace the wider enterprise employment catalogue. They are the sector-specific job test for construction/built-environment delivery.

## Governing rule

A job does not belong to exactly one F01-F29 enterprise function.

Each job has a primary sector delivery domain and can participate in multiple enterprise functions through explicit Governance, Delivery, Assurance and Support relationships.

## How NuBlox uses this register

For each job, implementation must progressively define:

1. Job Profile and competence expectations;
2. Governance/Delivery/Assurance relationships to enterprise functions and sector delivery domains;
3. responsibilities and activities;
4. required Managed Outputs/Deliverables;
5. business objects and information needed;
6. workflows/reviews/decisions;
7. deployment contexts;
8. permissions and delegated authority;
9. workload/assignment behaviour;
10. end-to-end job acceptance tests.

The target is not to build 84 isolated mini-applications.

The target is to provide shared enterprise runtimes which can be configured and deployed so each of these 84 jobs can perform the real work expected of that job.
