# Architecture Reference

Start with the [NuBlox Product Handbook](../handbook/README.md) and [System Architecture](../handbook/07-system-architecture.md).

This directory contains deeper architectural reference for engineers and reviewers.

## Governing references

- `architecture-principles.md` — non-negotiable product/application architecture principles.
- `interaction-architecture.md` — work contexts, drafts, edit leases, conflict safety and interaction runtime.
- `implementation-wave-01-foundation-runtime.md` — foundation runtime and implementation baseline.
- `native-capability-domain-hypothesis.md` — capability/domain hypotheses where still relevant.

Use ADRs in `../decisions/` for durable architectural choices.

Architecture reference should explain **how the product is built**. Product behaviour and business workings belong in the Handbook.
