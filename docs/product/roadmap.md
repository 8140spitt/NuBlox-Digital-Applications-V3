# NuBlox Product Roadmap

## Phase 0 — Product foundation

- Freeze product-layer architecture.
- Freeze canonical object families and invariants.
- Establish repository and engineering standards.
- Establish clean application shell and CI.

## Phase 1 — Enterprise Kernel

Implement the common identity and control spine first:

- tenant/platform identity;
- party/person/organisation;
- organisation structure and positions;
- contextual authority and permissions;
- canonical object identity/type/classification;
- lifecycle;
- workflow/work;
- decision;
- event/evidence/audit;
- information container;
- change;
- baseline/configuration/effectivity;
- integration/outbox.

## Phase 2 — Functional framework and deployment

- 29 function definitions;
- processes, activities and task definitions;
- job profiles and competence;
- functional deployment;
- assignments;
- native work-delivery runtime;
- deliverable requirements and items.

## Phase 3 — Construction & Built Environment

- 16 delivery domains;
- 84 job profiles;
- sector object types and relationships;
- design/construction/commissioning/handover work products;
- projects/contracts/packages/sites/systems/assets;
- representative end-to-end job experiences.

## Phase 4 — Functional depth

Implement complete native capabilities across all 29 enterprise functions using the shared kernel and runtime.

## Phase 5 — Connected ecosystem and migration

- reference-platform mappings;
- authoring adapters;
- ERP/PLM/CDE/BIM/EAM integrations;
- governed migration;
- federation where ownership remains external.
