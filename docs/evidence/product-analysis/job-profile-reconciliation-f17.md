# F17 Job Profile Reconciliation — Data, Analytics & AI

**Status:** employment-model reconciliation complete  
**Date:** 20 September 2026

All F17 source Job Profiles now have an explicit employment treatment.

Data strategy/governance/architecture, master/reference data, quality, engineering/platform, BI/analytics/data science, AI engineering/governance/MLOps, metadata/catalogue, data access and lifecycle are retained as distinct employment roles.

The canonical layer must separate Data Product/Dataset, platform infrastructure, metadata/lineage, reports/analyses/models, AI use cases/model versions/governance approvals and deployment evidence. Data access must resolve through the common authorization service rather than becoming a parallel permission system.
