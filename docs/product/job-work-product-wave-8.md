## Non-negotiable controls

### HCM

```text
Person != Worker Relationship != Job Profile != Position != Position Assignment
```

Recruitment, screening, onboarding, worker administration, employee-relations cases and offboarding remain separate case/lifecycle records.

### Identity and access

Identity administrators and data-access administrators **execute approved access grants**. Their Job Profiles do not create authorization authority.

```text
Request -> authority decision -> Access Grant -> provisioning -> review/certification -> revocation
```

### Data / AI

Dataset/Data Product, report, analytical model, AI use case, model version, risk assessment, approval, deployment and monitoring remain distinct.

### Cybersecurity

Security Policy, architecture/control patterns, vulnerability, patch, alert, threat intelligence, cyber incident, security test and cryptographic key/certificate lifecycles remain separate governed truths.
