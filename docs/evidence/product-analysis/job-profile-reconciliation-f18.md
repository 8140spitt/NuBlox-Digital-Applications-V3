# F18 Job Profile Reconciliation — Cybersecurity & Information Security

**Status:** employment-model reconciliation complete  
**Date:** 20 September 2026

All F18 source Job Profiles now have an explicit employment treatment.

Security strategy/policy/architecture, IAM security, vulnerability/patching, SOC/incident response/threat intelligence, penetration testing/application security, third-party risk, awareness, cryptography/PKI and security compliance remain distinct specialist jobs.

The product model must keep policy, architecture, access authority, vulnerability, patch, alert, threat intelligence, security testing, cyber incident and cryptographic-key lifecycles distinct. Security roles do not bypass the common delegated-authority and Access Grant model.
