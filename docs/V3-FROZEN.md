# NuBlox Digital Applications V3 — Frozen Reference

**Status:** FROZEN REFERENCE  
**Effective:** 26 September 2026

NuBlox Digital Applications V3 is no longer the active clean-slate product repository.

V3 is preserved intact as an evidence base containing implemented experiments, market research, reference studies, architectural decisions, migrations, tests, user-flow learning and capability analysis accumulated during V3 development.

## Rule

Nothing in V3 is automatically canonical for the next NuBlox product baseline merely because it was previously designed or implemented.

The next clean-slate baseline must re-derive the product architecture from business reality and may selectively promote V3 material only after explicit review.

## What V3 remains authoritative for

V3 remains authoritative only as evidence of what was researched, implemented, tested or decided within V3 itself.

Examples include:

- market-tool and product research;
- Windchill reference studies;
- enterprise Function / L2 / Activity research;
- CBE Job Profile research;
- implementation experiments;
- migration and persistence lessons;
- authentication, routing and control-plane experiments;
- UI/UX lessons;
- CI/test evidence;
- commercial and marketing research.

## What V3 does not automatically dictate

The clean-slate product must not automatically inherit:

- the F01–F29 taxonomy;
- the D01–D16 CBE taxonomy;
- the 1,510 Activity model;
- the current Tool Registry;
- the current provisioning model;
- the current database schema;
- current routes or navigation;
- current page/component structure;
- current migration history;
- current application code.

Each of those is evidence to be tested against the new enterprise model.

## Clean-slate sequence

The next product baseline starts from:

1. product definition;
2. enterprise model;
3. work model;
4. capability model;
5. object model;
6. control model;
7. evidence reconciliation;
8. only then software architecture, persistence, routes and UI.

V3 should therefore be read as a reference archive, not as the foundation to clone.
