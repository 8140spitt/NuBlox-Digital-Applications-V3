# F15 Job Profile Reconciliation — Human Resources / Human Capital

**Status:** employment-model reconciliation complete  
**Date:** 20 September 2026

All F15 source Job Profiles now have an explicit employment treatment. The 20 professional specialist roles are retained as reusable employment jobs.

Critical rule: **Person != Worker Relationship != Job Profile != Position != Position Assignment != Access Role**.

The current activity model incorrectly labels Job Profile and Position as one object and over-compresses recruitment/onboarding, payroll/compensation/benefits and worker/case records. These are now explicit architecture gaps.

A tenant may combine HR specialisms into one Position; NuBlox must not collapse the reusable job catalogue or derive permissions from those jobs.
