# 08 — User Experience & Workspaces

## Product experience

NuBlox must feel like one enterprise application, not 29 separate systems.

## Primary navigation

The target experience includes Home, My Work, Functional Areas, Deliver, Deliverables, Enterprise Data, Search and Administration.

## Home

Home answers who the user is operating as, which enterprise/project context is active, what requires attention, what is changing and where to go next.

## My Work

My Work is the actionable business inbox for work items, deliverables due, reviews, approvals, decisions, exceptions, overdue actions, inspections and cases.

## Functional Area workspace

Each F01-F29 workspace provides the operational environment for that business function.

It can include priorities, processes, work queues, object collections, decisions, reports/KPIs, exceptions and relevant configuration.

## Deliver workspace

Deliver provides cross-functional context around client/opportunity, bid/tender, contract, programme/project, site, package and asset/service.

It must not duplicate functional data.

## Deliverables workspace

Users must be able to see and manage required outputs by project, stage, discipline, package, organisation, responsible person/position, type, due date, state, revision, issue status and acceptance state.

## Object workspace

Every important business object should open consistently regardless of entry point.

Typical sections include overview, status, details, structure, relationships, deliverables, workflow, decisions, evidence, history and related transactions.

## High-volume work

Enterprise work needs grids, filtering, saved views, grouping, bulk edit, imports, validations, batch actions and exception handling.

Repeated one-record forms are not sufficient.

## Design and technical work

Deliverable workspaces should support previews, versions, markups, comments, comparisons and links to connected authoring tools where relevant.

## Field and mobile work

Site/service experiences prioritise today's assignments, site/location/asset context, checklists, readings, inspections, photos, labour, plant, materials, signatures and completion.

## Progressive disclosure

Users should see current context, current state, what is required, primary next actions, blockers/exceptions and evidence/history when needed.

The whole workflow graph should not be dumped onto every screen.
